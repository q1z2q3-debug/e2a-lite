16983:19:121. 奢摩他（Śamatha），译为止、寂静、一境性
16993:19:18核心：摄心不散，把心念收拢在一个所缘之上（呼吸、声音、一个字句、光明等），平息粗重的妄想躁动，令心稳定、安宁。
17003:19:34止的成果：心能够安放在一处，不容易被外境、念头带走，得到安宁、轻安。
17013:19:45止的特质：偏向收敛、凝聚、息乱；
17023:19:50可以没有深入的抉择简择，单纯是心的稳定。
17033:19:562. 毗婆舍那（Vipaśyanā），译为观、慧观、简择观察
17043:20:03核心：在心念稳定的基础上，观察、简择、照见一切所缘的特质：无常、无自性、苦、空。
17053:20:16不是单纯静静看着，里面带有智慧的辨别：觉察这个念头从哪里来、往哪里去，觉察感受生起、停留、消散，觉察能观、所观的分界。
17063:20:33观必须依托稳定的止作为地基；
17073:20:37心散乱动荡的时候，很难升起清晰、持续的慧观。
17083:20:44止观的配合次序：以止摄心，心净稳定；
17093:20:50以观简择，照见缘起。
17103:20:53只有止没有观，是单纯的禅定，可以得喜乐、安宁，属于禅那，属于六度里面的禅定度，不自带破执的智慧；
17113:21:08只有观没有止，心念浮躁，观容易变成头脑不断分析、评判，不是真观。
17123:21:18俗见勘破，
17133:21:21误区一：能打坐入定、内心一片宁静，就是般若、就是开悟。
17143:21:31正见：宁静是奢摩他的成果，属于善受、定境。
17153:21:38定境是因缘所生的一种状态，依然是所缘之相，可以被贪恋。
17163:21:46执着寂静，就是法执，落在“静好、动不好”的取舍之中，不是般若。
17173:21:56误区二：我可以清清楚楚看见念头升起消失，这就是观照般若，就是心经的行深般若。
17183:22:09正见：清晰看见念头，是毗婆舍那的基础功夫。
17193:22:15还要进一步照见：这个“看”的能观者，和被看的念头，都是缘起幻现，无坚固自性。
17203:22:27如果还有一个独立的“我在看念头”，仍然卡在能所二分，只是观的功夫，还没有契入实相般若。
17213:22:38误区三：般若很高，普通人先只管修止，观和慧以后再说。
17223:22:46正见：慧的简择，可以同步在日常发生。
17233:22:52在疼痛、愤怒、欢喜升起的当下，觉察它无常、不可抓取，这就是简易的毗婆舍那，不必等到禅定功夫很深之后再起步。
17243:23:09止是打磨心的稳定性，慧是时时的简择照见，二者可以并行。
17253:23:17误区四：修般若，不需要止，只要不断觉察就够了。
17263:23:24正见：凡夫心念习气粗重，没有止的收敛，觉察很容易被念头卷走，变成不断追逐思绪、评判境界。
17273:23:38奢摩他的作用，就是创造稳定的心地，让慧观有持续扎根的条件。
17283:23:47止是助缘，不可或缺，但不是究竟。
17293:23:52误区五：庄子的坐忘，就是奢摩他。
17303:23:56正见：坐忘，是消融是非人我的分别，和止有相近的收敛效果；
17313:24:05但坐忘重在遗忘分别、同于大化，缺少“简择无我、照空”这一层毗婆舍那的慧观内核。

22364:29:48空性太极，是统摄阴阳、不落在任何一蕴边界的本体。
22374:29:55阴阳可以有承载、感受、分别、迁流、觉知的种种作用，但是太极本身，不被这一套聚合系统锁定。
22384:30:09五、补论：五蕴不只是杯，也是管
22394:30:14前文以杯释五蕴：色为底，受想行识为四壁；
22404:30:20五类因缘合拢，杯相显现，杯中空也同时显现。
22414:30:26这是从“聚”看五蕴：它是一个可执取的身心之器。
22424:30:32但五蕴不只是盛东西的器。
22434:30:36它同时是生命流转的通道：感受进来，想蕴取相，行蕴推动，识蕴了别，又返回身口意。
22444:30:47若只有杯，容易把“空”读成杯腹里那块空处，也容易把修行读成“把杯里的东西倒空”。
22454:30:57于是同一套五蕴，再立一管。
22464:31:01杯与管的配位不同，先立骨节：
22474:31:05杯：色为底；
22484:31:07受、想、行、识为四瓣竖壁，各九十度，沿杯高竖切通体。
22494:31:16杯的空，是“容”。
22504:31:19管：色、受、想、行、识为五瓣纵壁，各七十二度，沿管长通体。
22514:31:28管横放，没有单独的底；
22524:31:32色也是一瓣，不是底，不是内环。
22534:31:36管的空，是“通”。
22544:31:39两器并置，不合成一器；
22554:31:42同框只作对照，不作物理连接。
22564:31:46不是五层同心，不是把管身横切成五条，不是沿管长把管截成五段。
22574:31:56最后一条最要紧。
22584:31:59五蕴若画成五层同心，便成“色在外、识在内”的实有条带；
22594:32:07若画成沿长度切五段，便成五个前后相接的“我”。
22604:32:13两种画法都把“和合”重新实体化，正好与“皆空”相反。
22614:32:20缺一瓣，杯是整条侧壁缺口，水漏；
22624:32:24管是沿全长缺口，水漏，压力也守不住。
22634:32:30缺的不是装饰，是器之所以为器的那道闭合。
22644:32:37六、有、无、用：壁、腔、通
22654:32:41管立起来，有、无、用三层就清楚了：
22664:32:47壁，是五蕴，是有；
22674:32:50腔，是空，是无；
22684:32:53由腔而能流，是通，是用。
22694:32:57老子说“埏埴以为器，当其无，有器之用”。
22704:33:03陶土做成器，器之所以有用，不在陶土堆得多厚，而在那一段被器壁围出来的空。
22714:33:15世人多看见壁，少看见空；
22724:33:18多执着有，少看见用。
22734:33:22但杯的空，不止杯腹那一块。
22744:33:25杯腹之内，是“容”的空；
22754:33:29杯壁之外，仍在这只杯的“无”里。
22764:33:32前者是已被五蕴有型利用的空，后者是未被有型利用、却仍属于杯的空。
22774:33:42老子说有无相生：有，是已被五蕴有型利用的部分；
22784:33:48无，是未被有型利用、却仍属于杯的部分；
22794:33:54有无相生，杯才成其用。
22804:33:58这不是把杯掏空。
22814:34:00把杯掏空，仍然在“有”上用力：想着把里面的东西拿掉，再得一个空。
22824:34:10般若说的空，是看见杯壁的边界、杯内杯外的分界，本非实有。
22834:34:19空不是一件可以拿到的物体，是边界不实之后的通透。
22844:34:26若只把空当作“阴尽阳生”的对面，仍落在阴阳对待里。
22854:34:32阴是实体，阳是空与无；
22864:34:36但太极之无，统摄阴阳，不是简单的阳之无。
22874:34:42它不在杯内，也不在杯外；
22884:34:46不增不减，不垢不净。
22894:34:49杯内空、杯外空、杯壁、杯用，都在太极之无中起。
22904:34:56所以“无中生有”，不是先有一片虚空，再从虚空里造出陶土；
22914:35:04是见有之际，已见其无；
22924:35:08见无之际，已见其用。
22934:35:11有无不是两截，是同一只器的两面。
22944:35:16三身也可借这只管看：法身为体，报身为修证所感的功德受用，应身为随缘应化。
22954:35:27三身不是三只管，是同一管的体、受用、应现。
22964:35:35体不离开壁，用不离开腔；
22974:35:39随缘放下，不是把管丢掉，是不把某一节壁、某一段流当成“我”。
22984:35:48七、五蕴管壁自照法：看壁厚，不看总分
22994:35:54古来五蕴之说，多停在名相。
23004:35:57落到当下，可以把它折成二十问：五蕴各四问，问四个面——把它当成我、拿它当尺子、由它牵动全蕴、为它立一个框。
23014:36:14每题按最近一个月的身口意反应，记零到四分：从不、很少、有时、经常、几乎每天。
23024:36:24每一蕴四题，满分十六分；
23034:36:28分数不是成绩，只用来把该蕴的壁厚显出来。
23044:36:34一蕴分高，壁就厚；
23054:36:37分低，壁就薄。
23064:36:39五瓣壁厚合围，端面留下一个孔。
23074:36:43孔不是装饰，是这只管当下还能不能通。
23084:36:49读法只有三层：
23094:36:52先看最厚的一瓣。
23104:36:55最厚处，是当下最容易被当成“我”的地方，也是这一轮要照的功课。
23114:37:03再看最薄的一瓣。
23124:37:06最薄处，可能是可以借力的松处；
23134:37:10也可能是失养、回避、麻木。
23144:37:14薄不等于好，薄到塌，同样不成器。
23154:37:18最后看孔形。
23164:37:20开、半、缝、闭、实心，不是说好坏，是说这只管现在是通、偏通、偏塞，还是已经不通。
23174:37:34五瓣薄而匀，孔开着，是“开”；
23184:37:38但薄到没有壁，器也不成立。
23194:37:42较匀而孔留一半，是“半”；
23204:37:45偏和，不是已和。
23214:37:48最厚一瓣把孔挤偏，是“缝”；
23224:37:52偏合，不是和。
23234:37:55三瓣以上偏厚，或总分已高，孔合上，是“闭”；
23244:38:02闭合不是和。
23254:38:04五瓣俱厚，孔尽，是“实心”；
23264:38:08空尽，管已不成管。
23274:38:11零分不自动等于“和”。
23284:38:14有人是松，有人是麻，有人是不敢碰。
23294:38:20要看它是不是有气、有觉、有回应。
23304:38:24自照不是给自己发一张“空”的证书。
23314:38:28行修落在最小处：每次只取最厚一瓣，做一个动作。
23324:38:35把“我就是这样”改成“我这里有这一层”；
23334:38:40把“必须马上”改成“我可以晚一点”；
23344:38:43把“他为什么这样”改成“我此刻在护什么”。
23354:38:47七天后重答，看壁有没有薄一分，孔有没有通一分。
23364:38:54不是求开，是求通。
23374:38:58断舍离也在这里落地。
23384:39:01断，不是把东西全扔掉，是见“无我”而不再把五蕴当实我；
23394:39:09舍，不是舍掉五蕴，是舍掉对五蕴的固化使用；
23404:39:16离，不是逃离人间，是离执之后的自在。
23414:39:22贪、嗔、痴、慢、疑，都是“执有”的不同面孔；
23424:39:29断的不是某一件事，是那一道把壁厚当成“我”的认定。
23434:39:36幸福也不在“有”的堆高。
23444:39:39色身要养，受想行识要照；
23454:39:43贵身爱身，不是供身相，不是把身体修成一件更好的作品。
23464:39:50人身难得，幸福与五蕴相生：借色身来感受，借受想来辨认，借行来落地，借识来觉照；
23474:40:03但不把任何一蕴当作“我”。
23484:40:06色即是空，空即是色；
23494:40:10受想行识，亦复如是。
23504:40:14幸福不是把有拿掉，是在有上不执有。
23514:40:20生命有限，是色身之限；
23524:40:23破执之后，生命在当下无限。
23534:40:27不是把百年拉成千年，是在一呼一吸之间，见到不被百年所限的那一面。
23544:40:37观自在，不是把管壁修到没有；
23554:40:40是照见壁厚、孔径、流向，仍不被它定义。
23564:40:47能照见，已经退了一步；
23574:40:50退一步，孔才可能通。
23584:40:53是名管，非管，故名管：五瓣、空腔、通流，因缘假合；
23594:41:03离瓣无管，离空无通，离通无用。
23604:41:07可用而不可执，能行而不滞。
23614:41:11杯以容，管以通。
23624:41:14容者，五蕴可聚；
23634:41:17通者，五蕴可流。
23644:41:19照见五蕴皆空，不是把杯打碎、把管塞死；
23654:41:25是见其聚合无体、流通无主，于是能用而不执，能行而不滞。
23664:41:35八、修学要点（附录结语）
23674:41:38很多人误解五蕴皆空，走向两种偏失：
23684:41:441. 断灭见：追求没有身体、没有感受、不起念头，强行压伏心念、隔绝感知；
23694:41:552. 放任见：既然一切皆空，于是随意造作，无所谓取舍。
23704:42:03正解：五蕴是舟，空是彼岸。
23714:42:07舟不是岸，但渡河离不开舟。
23724:42:11佛说五蕴（舟，承载渡人），即非五蕴（舟非岸，不可执舟为我、为实相），是名五蕴（善用舟而不困于舟）。
23734:42:26照见五蕴皆空，就是在一切色、受、想、行、识当下，清清楚楚觉知它的缘起、无常、无自性；
23744:42:41照常见闻、感受、思考、觉知，却不被五蕴编织的“自我边界”困住。
23754:42:51这正是整部《心经》的起点，也是后面“心无挂碍”的根基。
23764:42:58对应正文：观自在菩萨，行深般若波罗蜜多时，照见五蕴皆空，度一切苦厄。

23784:43:23前置总纲：十二因缘，是佛陀揭示的时间维度上的缘起循环，是一套说明迷惑、造作、受苦、生死流转的因果链条，属于形而下的生生器相。
23794:43:41正文“无无明，亦无无明尽，乃至无老死，亦无老死尽”，不是否定因果现象的显现，而是不把这条流转链条、以及“断除流转”的还灭，

23814:44:02一、总叙：何为十二因缘
23824:44:06十二因缘，又称十二支缘起，分为流转门、还灭门，是纵向的时间因果序列：
23834:44:17流转门（顺流，无明→老死）：众生沉沦生死、受苦的循环
23844:44:26无明 → 行 → 识 → 名色 → 六入 → 触 → 受 → 爱 → 取 → 有 → 生 → 老死
23854:44:31还灭门（逆流，老死尽→无明尽）：修行离苦，止息循环的次第
23864:44:40老死尽 → 生尽 → 有尽 → 取尽 → 爱尽 → 受尽 → 触尽 → 六入尽 → 名色尽 → 识尽 → 行尽 → 无明尽
23874:44:47套用《金刚经》范式：
23884:44:51佛说十二因缘：因缘相续，环环相生。
23894:44:56迷惑则造作，造作则招苦，现象层面确有这套因果次第，用来观察轮回、苦的由来，是教化假名建立的时间链条。
23904:45:10即非十二因缘：链条上没有独立不变、自主主宰的实体。
23914:45:18无明不是一个实有的“黑暗之物”，老死也不是一个固定终点；
23924:45:25流转不是锁死的宿命，还灭也不是一个可以抓牢的实有果境，本心不受这条时间边界束缚。
23934:45:36是名十二因缘：不妨依此链条观修，知缘起、知苦本；
23944:45:44但证入实相，不住流转、不住息灭二边。
23954:45:49和四圣谛的区别：四圣谛是横向因果：苦果、苦因、灭果、道因；
23964:45:59十二因缘是纵向时序：一步一步，从迷惑开始，展开完整的生命循环。
23974:46:08和五蕴的联动：整个十二因缘的运转载体，就是五蕴身心。
23984:46:17五蕴是承载这套循环的器，十二因缘是器内部生生不息的迁化流程。
