e2a-lite · 电 子 书 转 有 声 书

一本书，一副字幕，一条命令

纯 CPU · 句级精确时间轴 · 改一句只重算一句

把 txt／md／html／docx／epub／pdf 丢进去，出来 mp3、带章节的 m4b、逐句对齐的 srt／vtt，还有一份可核对的 manifest。字幕时间不是估的——每句单独合成、逐句计时再累加；渲染完由 check 验一遍时间轴、静音与响度，不过关就报错。

试 听

《般若波罗蜜多心经》全篇，57.7 秒，两章（正文／咒），中文音色 zh_CN-huayan-medium。 字幕 srt · 章节版 m4b · manifest。 这台机器是 2 核 3 GB 无显卡，合成用时 6.9 秒。

真人音色 · 《心经通释》分释篇十 节选（1 分半）
平台真人音色逐段朗读，本项目负责实测停顿切句、字幕与章节；字幕。 整章 2,067 字 → 9 分 52 秒、107 条字幕，拼装与质检 22.6 秒。

三 条 命 令

pip install -e .
python3 tts.py fetch --voice zh_CN-huayan-medium
python3 tts.py build --in 书.md --out out/     # mp3 + m4b + srt + vtt + manifest
python3 tts.py check --audio out/书.mp3 --srt out/书.srt

# 朗读前去掉（阴）（阳）（太极）等框架标注与图注，字幕同步
python3 tts.py assemble --in 书.md --wavs 逐段/ --out out/ --clean

# 换引擎：任何 TTS 的音频，一样拿到精确字幕与章节
python3 tts.py assemble --in 书.md --wavs 逐句/ --out out/ --trim --engine 平台TTS
python3 tts.py assemble --in 书.md --wavs 逐段/ --out out/   # 一段一文件，按实测停顿切句

不 做 什 么

  • 音色本机不做克隆。3 GB 内存放不下 XTTS，要克隆音色请上有显卡的机器。
  • 表演Piper 是「稳、清楚、没有演技」，不是真人朗读；情绪化朗读需换引擎或真人。
  • 多音字古文断句按规则切，个别字会读错；靠小句长与手改源文缓解。
  • 章节依赖 Markdown 标题或「第 N 章／篇／回」；没标题的长文按整篇一章。
